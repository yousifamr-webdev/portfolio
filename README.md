# Yousif Amr Portfolio

A personal portfolio presenting Yousif Amr's software engineering projects, experience, technical skills, and contact information, with tailored views for clients and recruiters.

## Stack

Vite, React 19, TypeScript, Tailwind CSS, and Framer Motion.

## Scripts

- `npm install` — install dependencies
- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run lint` — run ESLint
